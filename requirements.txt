# CUDA runtime for CTranslate2. NOT pulled in by faster-whisper, so without these
# the GPU path fails at model load — and whisper_engine.py deliberately re-raises
# a non-OOM failure rather than demoting to CPU, so the pipeline stops instead of
# silently taking days. config.py adds their bin/ directories to PATH on import,
# which is why `import config` must precede `import faster_whisper`.
#   cublas64_12.dll  <- nvidia-cublas-cu12
#   cudnn64_9.dll    <- nvidia-cudnn-cu12 (CTranslate2 4.x needs cuDNN 9, CUDA 12)
# CPU-only machines can skip both; set WHISPER_DEVICE = "cpu" in config.py.
